1. Yönetici Özeti

Görüntüproje, iki birbirini tamamlayan ama farklı hedeflere sahip sistemden oluşur:

  • Project HYDRA (smarthome/ + komuta_merkezi/): Tek kullanıcılı kişisel akıllı ev laboratuvarı. Mosquitto, n8n, Frigate ve Flutter kontrol paneli ile çalışır. Kişi algılandığında mobil alarm ve PC'de oyun portalı açma (tv_ajani) özellikleri vardır.
  • BulutSistem (bulutsıstem/): Çok kiracılı (multi-tenant) akıllı ev ve IP kamera platformu. FastAPI, PostgreSQL, kimlik doğrulamalı MQTT, go2rtc, Frigate, edge agent tüneli ve FCM push altyapısı içerir.

HYDRA, BulutSistem'in kavramsal öncülüdür: aynı oda/cihaz isimleri, senaryo mantığı ve hydra/master_kontrol kavramı BulutSistem'e taşınmıştır; ancak BulutSistem'de tenant izolasyonu, JWT auth ve üretim-hazırlık güvenlik katmanları eklenmiştir.

Önemli: HYDRA ve BulutSistem Frigate için aynı host portunu (5000) kullanır. İkisini aynı anda tam çalıştırmayın; günlük kullanımda birini seçin.

10. Otomasyon Akışları

10.1 HYDRA — Kişi Algılama → Tepki

[Telefon] IP Webcam :8080/video
    → Frigate telefon_arka → frigate/telefon_arka/person
    → komuta_merkezi ALARM (ringtone)

[PC] /dev/video0
    → Frigate pc_kamera → frigate/pc_kamera/person
    → tv_ajani.py → RetroCloud oyun portalı aç/kapa

10.2 BulutSistem — Kişi Algılama Pipeline

Kamera → go2rtc → Frigate (person)
    → MQTT frigate/{stream_key}/person
    → API detection_service (bulut_service)
    → t/{tenant}/cameras/{camera_id}/person
    → Mobil MQTT alarm + detection_events DB + FCM push (opsiyonel)

10.3 BulutSistem — Senaryo Otomasyonu

API POST /automations/home
    → t/{id}/senaryo/evedonus + t/{id}/hydra/master_kontrol = "1"

API POST /automations/away
    → t/{id}/senaryo/evdencikis + t/{id}/hydra/master_kontrol = "0"

API ayrıca gelen senaryo MQTT mesajlarını dinleyip master_kontrol yayınlar

16. Riskler, Eksikler ve Notlar

Kritik: HYDRA ve BulutSistem Frigate port 5000'i paylaşır — aynı anda çalıştırmayın.
  • Frigate config çakışması (HYDRA): config.yml (aktif) vs config.yaml (boş) — hangisinin okunduğunu doğrulayın.
  • bulut-oyun harici bağımlılık: tv_ajani.py /home/yasir/bulut-oyun/index.html dosyasına bağlı; repoda yok.
  • Gerçek akıllı cihaz firmware'i: Her iki sistemde de MQTT'ye abone fiziksel cihaz repoda yok; simülasyon.
  • FCM: Varsayılan kapalı; Firebase projesi + service-account.json gerekli.
  • Üye daveti: API hazır, mobil UI yok.
  • CORS: BulutSistem API allow_origins=["*"] — üretimde kısıtlanmalı.
  • MQTT TLS: Her iki sistemde de yok — internete açmadan önce eklenmeli.
  • ev/otomasyon/zaman (HYDRA): komuta_merkezi gönderir ama işleyen n8n workflow repoda export edilmemiş.
  • go2rtc 400 hataları: Kamera IP erişilemez olduğunda normal; ağ/kamera kontrolü gerekir.

16.1 Kendi Kullanımın İçin Yeterlilik

BulutSistem, kendi evinde güvenlik kamerası + alarm + akıllı ev kontrolü için yeterli. HYDRA daha basit tek kullanıcılı alternatif. Günlük kullanımda BulutSistem'i tercih edin; HYDRA'yı kapalı tutun veya Frigate portunu ayırın.
