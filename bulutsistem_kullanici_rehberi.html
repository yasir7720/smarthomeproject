BulutSistem — Sıradan Kullanıcı Rehberi

Proje: BulutSistem (Akıllı Ev + Güvenlik Kamerası)
Konum: /home/yasir/görüntüproje/bulutsıstem/
Kim için: Sistemi ilk kez kuran ve günlük kullanacak kişi
Tarih: 12 Haziran 2026

Bu rehber, BulutSistem'i sıradan bir kullanıcı gibi sıfırdan kurup kullanmanız için hazırlanmıştır. Teknik bilgi gerekmez; adımları sırayla takip etmeniz yeterlidir.

Ne yapacaksınız?

  • Hesap açacaksınız
  • Telefon kamerasını sisteme bağlayacaksınız
  • Canlı görüntü izleyeceksiniz
  • Kişi algılanınca alarm çalacak
  • Ev cihazlarını (lamba, priz vb.) kontrol edeceksiniz
Önemli: HYDRA (smarthome/komuta_merkezi) ile BulutSistem aynı anda tam açılmamalıdır. İkisi de Frigate için 5000 portunu kullanır. Günlük kullanımda sadece BulutSistem'i çalıştırın.

Bölüm A — Ön Hazırlık

Adım 0 — Gereksinimler
  • Bir Linux PC (sistemin çalışacağı bilgisayar)
  • Docker ve Docker Compose kurulu
  • Flutter SDK (mobil uygulama için)
  • Android telefon veya emülatör
  • Telefonda IP Webcam uygulaması (ücretsiz)
  • Telefon ve PC aynı WiFi ağında

Bölüm B — Sistemi Başlatma (PC)

Adım 1 — BulutSistem'i ayağa kaldırın

Terminal açın ve şu komutları çalıştırın:

cd /home/yasir/görüntüproje/bulutsıstem
docker-compose up -d --build

İlk seferde 2–5 dakika sürebilir. Bittikten sonra kontrol edin:

curl http://localhost:8000/health

Şunu görmelisiniz: "status": "ok"

Adım 2 — Çalışan servisleri doğrulayın
ServisAdresNe işe yarar?
APIhttp://localhost:8000/docsTüm işlemler (Swagger arayüzü)
Veritabanıhttp://localhost:8085Adminer — verileri görme
Frigatehttp://localhost:5000AI kamera / kişi algılama

Adım 3 — PC'nizin yerel IP adresini öğrenin
hostname -I

Çıkan ilk adresi not alın (örnek: 192.168.1.10 veya 10.80.15.57).

Bu IP'yi mobil uygulamada API adresi ve MQTT Host için kullanacaksınız.

Bölüm C — Hesap Açma

İki yol var. Mobil uygulama önerilir.

Adım 4 — Mobil uygulamayı başlatın
cd /home/yasir/görüntüproje/bulutsıstem/mobile
flutter pub get
flutter run

Telefon bağlıysa telefonda, yoksa Chrome'da açılır:

flutter run -d chrome
Adım 5 — API adresini ayarlayın
Nereden bağlanıyorsunuz?API adresi
PC'de Chromehttp://localhost:8000
Android emülatörhttp://10.0.2.2:8000
Gerçek telefon (aynı WiFi)http://PC_IP:8000 (ör. http://192.168.1.10:8000)
Adım 6 — Kayıt olun
  1. Uygulamada Kayıt Ol sekmesine geçin
  2. E-posta girin (ör. benim@email.com)
  3. Şifre: en az 8 karakter
  4. Ad soyad girin
  5. Ev adı girin (ör. Benim Evim)
  6. Kayıt Ol butonuna basın

Kayıt olunca otomatik giriş yapılır ve size özel bir ev (tenant) oluşturulur.

Arka planda şunlar otomatik olur:

  • 4 varsayılan cihaz eklenir (salon lamba, TV priz, yatak odası lamba, mutfak priz)
  • MQTT kullanıcı adı ve şifreniz oluşturulur
  • Edge agent anahtarınız üretilir
Alternatif — Tarayıcıdan kayıt: http://localhost:8000/docs adresinde POST /api/v1/auth/register endpoint'ini kullanabilirsiniz.

Bölüm D — Telefon Kamerasını Bağlama

Adım 7 — IP Webcam uygulamasını hazırlayın
  1. Telefona IP Webcam uygulamasını kurun
  2. Uygulamayı açın → Sunucuyu başlat
  3. Ekranda görünen IP adresini not alın (ör. 192.168.1.105:8080)
  4. Telefon ve PC aynı WiFi'de olmalı

Test: PC tarayıcısında şunu açın:

http://TELEFON_IP:8080/video

Canlı görüntü geliyorsa kamera hazır.

Adım 8 — Kamerayı BulutSistem'e ekleyin

Mobil uygulamada Dashboard ekranında:

  1. IP Webcam Ekle bölümüne gidin
  2. Telefon IP'sini yazın (ör. 192.168.1.105)
  3. Port: 8080
  4. Kamera adı verin (ör. Telefon Kamerası)
  5. Ekle butonuna basın

Başarılıysa:

  • Durum: active
  • Dashboard'da canlı MJPEG görüntüsü görünür

Hata alırsanız: telefon IP'si değişmiş veya IP Webcam kapalı olabilir — Adım 7'yi tekrarlayın.

Adım 9 — Canlı yayını izleyin

Dashboard'da kamera kartının altında canlı görüntü akar.

Arka planda şu olur:

Telefon → go2rtc → API proxy → Mobil uygulama

Tarayıcıdan da test edebilirsiniz: Swagger'da POST .../stream-token ile alınan mjpeg_url adresini tarayıcıda açın.

Bölüm E — Güvenlik Alarmı

Adım 10 — MQTT alarm ayarını yapın

Dashboard'da Güvenlik Alarmı panelinde:

AyarDeğer
MQTT HostPC'nin yerel IP'si (Adım 3'teki) — localhost değil
Kişi algılanınca alarmAçık

Emülatör kullanıyorsanız MQTT Host: 10.0.2.2

Bağlantı başarılıysa logda görürsünüz:

MQTT alarm bağlantısı aktif (192.168.x.x:1884)

Kullanıcı adı ve şifre API'den otomatik alınır; elle girmenize gerek yok.

Adım 11 — Alarmı test edin
  1. Frigate çalışıyor mu kontrol edin: http://localhost:5000
  2. Kameranın önüne geçin / hareket edin
  3. Mobilde panel kırmızıya döner
  4. Alarm sesi çalar
  5. Alarmı Sustur ile kapatabilirsiniz

Algılama akışı:

Kamera → Frigate (kişi) → MQTT → Mobil uygulama → ALARM
Push bildirim (opsiyonel): Uygulama kapalıyken de alarm istiyorsanız Firebase kurulumu gerekir. Detay: bulutsıstem/fcm/README.md. Günlük kullanımda uygulama açıkken MQTT alarm yeterlidir.

Bölüm F — Ev Cihazları ve Otomasyon

Adım 12 — Cihazları kontrol edin

Dashboard'da Cihazlar bölümünde kayıtta oluşan 4 cihazı görürsünüz:

CihazOda
Ana Lambasalon
TV Prizsalon

Anahtarları açıp kapatın. Her değişiklik MQTT üzerinden gönderilir.

Not: Gerçek akıllı priz/lamba bağlı değilse komut gider ama fiziksel cihaz tepki vermez — bu normaldir.

Adım 14 — Kamera silme

Artık kullanmadığınız kamerayı Dashboard'daki Sil butonu ile kaldırabilirsiniz.

Bölüm G — Günlük Kullanım Rutini

Her gün sistemi kullanmak için:

  1. PC'yi açın
  2. cd bulutsıstem && docker-compose up -d (zaten çalışıyorsa gerek yok)
  3. Telefonda IP Webcam'i başlatın
  4. Mobil uygulamayı açın → otomatik giriş (token kayıtlıysa)
  5. MQTT Host'un doğru olduğunu kontrol edin
  6. Kullanmaya başlayın

Kapatmak için:

cd /home/yasir/görüntüproje/bulutsıstem
docker-compose down
